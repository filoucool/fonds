Fonds on disk

The same commits, in two places.

  1. A force-push leaves the old main reachable from refs/archive/keep/.
  2. A deleted branch stays under refs/archive/history/.
  3. If the host returns 404, the directory is still on disk.

Hosting is not preservation.

In 2026, an overbroad takedown temporarily disabled about 8,100 repositories. The copies already archived stayed.

Sometimes the code that vanishes isn’t yours.

What remains

A directory, not an account.

Fonds is a self-hosted archive for the repositories you choose, on disks you control.

01

The folder

Each project is a directory. The manifest says what is inside. Git checks the objects.

  • repository.gitbare git, plus archive refs
  • archive.jsonmanifest
  • checksums.jsonsha256 of the files

02

The refs

Before a fetch publishes, the previous tips are copied. Then the branch is allowed to move.

  1. refs/heads/main 4f1c8a2b3c4d b70e33c91aa0
  2. refs/heads/feature 9aa21d0e11b8
  3. refs/archive/keep/4f1c8a2b3c4d
  4. refs/archive/history/heads/main/…
  5. refs/archive/keep/9aa21d0e11b8
  6. refs/archive/history/heads/feature/…

03

The catalog
